## 6. الحركة والتفاعل

- وميض المؤشر هو الحركة المستمرة الوحيدة.
- التبويب النشط يُمرَّر إلى المنتصف عند الحاجة دون التأثير على تمرير الصفحة.
- النسخ يعمل عبر Clipboard API مع مسار احتياطي.
- نموذج التواصل يفتح واتساب فقط، ولا يوجد خادم أو تخزين محلي.
- لا يوجد عدّاد ولا `localStorage` ولا اشتراك بريدي.
- `prefers-reduced-motion` يوقف وميض المؤشر وجميع الانتقالات.

## 8. إمكانية الوصول والجودة

المطبّق:

- `lang="ar"` و`dir="rtl"` على مستوى الصفحة.
- نافذة الطرفية `dir="ltr"`، والنصوص العربية داخل سياقها.
- عنوان `h1` واحد لكل صفحة وعناوين `h2` للبطاقات.
- `aria-label` للتنقل والروابط الخارجية والأزرار ذات المعنى.
- `aria-current="page"` للتبويب النشط.
- رسائل النسخ والنماذج تحمل `role="status"` و`aria-live="polite"`.
- حالات تركيز واضحة عبر `:focus-visible`.
- دعم تقليل الحركة.
- تباين مرتفع للنصوص الأساسية.
- لا توجد روابط نائبة أو بريد إلكتروني وهمي.

فرص تحسين لاحقة:
