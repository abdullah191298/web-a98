# Abdullah Mohammed Hussein – الموقع الشخصي (A98)

موقع شخصي متعدد الصفحات بأسلوب "طرفية فاتحة" (light terminal interface).

## الصفحات
1. **الرئيسية (`index.html`)** — الترحيب، نبذة، وسوم المجالات، وبطاقات تنقل.
2. **نبذة (`about.html`)** — تعريف شخصي، حقائق مختصرة، واهتمامات.
3. **مهارات (`skills.html`)** — Python، C#، تطوير الويب، CAD/CAM دون نسب أو مستويات.
4. **مشاريع (`projects.html`)** — مساحة مشاغل مع النص «قريباً نبدأ التسجيل».
5. **تواصل (`contact.html`)** — واتساب، المعرّف `@abdullah191298`، وروابط GitHub وLinkedIn وX وInstagram.

## الخصائص
- نافذة طرفية فاتحة التصميم.
- نظام ترجمة ثنائي اللغة (العربية / الإنجليزية) مع حفظ التفضيل في `localStorage`.
- لا توجد قاعدة بيانات ولا نموذج اشتراك بريدي.
- جميع الروابط الاجتماعية تستخدم المعرّف `@abdullah191298`.
- التصميم متجاوب (يتكيف من 390px إلى 1440px).
- وصولية: `lang="ar"`، `dir="rtl"`, `aria-label`، `aria-current="page"`.
- تم تحسين تباين الألوان للأزرار غير النشطة.
- شريط العنوان موحد في كل الصفحات: العنوان في الوسط، وشعار A98 مع زر تغيير اللغة في أقصى اليمين.
- وسوم Open Graph وTwitter Card للمشاركة الاجتماعية.

## الملفات
- `DESIGN.md` — دليل التصميم والواجهة الشامل (الألوان، الخطوط، المكونات، الاستجابة، الوصولية).
- `TRANSLATION.md` — نظام الترجمة ثنائي اللغة، مفاتيح `data-key`، وقواعد RTL/LTR.
- `GLOSSARY.md` — قاموس النصوص والمفاتيح لكل صفحة باللغتين العربية والإنجليزية.
- `assets/css/styles.css` — ملف التنسيقات.
- `assets/js/main.js` — سكربت الوظائف (النسخ، واتساب، تنقل التبويب، تغيير اللغة).
- `assets/js/translations.js` — كائن الترجمات باللغتين العربية والإنجليزية.

## التجربة
يمكن فتح الصفحات في المتصفح على مقاسات 1440px، 500px، 390px للتأكد من الاستجابة.
