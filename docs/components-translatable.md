# المكونات القابلة للترجمة

## 1. الأزرار (`.btn`)
- نصوص الزر: `innerText` أو `value`.
- الحالات `hover` و `active`: تغيير اللون فقط، لا يغير النص.
- أزرار النسخ (`data-copy`): النص يظهر في `.copy-status`.

## 2. البطاقات (`.card`)
- `.card h2`: العنوان الرئيسي للبطاقة، **يمكن ترجمته**.
- `.card p`: الوصف، **يمكن ترجمته**.
- `.card .chips .chip`: الوسوم، كل كلمة **يمكن ترجمتها** (مثل: "Python" -> "بايثون"، "C#" -> "سي شارب" ولكن يمكن الاحتفاظ internationally).
- `.card-meta`: المعرف والأيقونة، **يمكن ترجمتهما** أو تركهما internationals.

## 2. الحالة الفارغة (`.empty-state`)
- `h2`: العنوان "قريباً نبدأ التسجيل" **لا يُترجم** (phrase exact).
- `p`: الوصف **يمكن ترجمته**.
- الأزرار داخلها: "تواصل معي"، "العودة للرئيسية" **يمكن ترجمتهما**.

## 3. نموذج التواصل (`.contact-form`)
- `label[for="contact-name"]`: **"الاسم"**.
- `label[for="contact-message"]`: **"الرسالة"**.
- `placeholder` في inputs: **"اسمك"**، **"اكتب رسالتك هنا..."**.
- `btn.btn-primary`: **"إرسال عبر واتساب"** .
- `btn[type="button"].copy-phone`: **"نسخ الرقم"**.
- `btn[type="button"].copy-handle`: **"نسخ المعرّف"**.
- `.form-status`: محتوى ديناميكي يتغير ( `[ok]`، `[err]` ).
- `.copy-status`: محتوى ديناميكي.

## 3. شريط الحالة (`.statusbar`)
- `sb-branch`: "⎇ main" (رمز زخرفي، **يمكن الاحتفاظ به كما هو** أو ترجمته إلى "الفرع الرئيسي").
- `sb-ok`: "جاهز" (يمكن ترجمته إلى "Prepared" أو الاحتفاظ به بالعربية).
- `sb-right span:first-child`: "UTF-8" (يمكن تركه تقنية كما هو).
- `sb-right span:last-child`: "Python · C#" (يمكن ترجمة "Python" و "C#" ولكن **يفضل الاحتفاظ internationally**).
- `A98 © 2026`: الشارة والحقوق، **لا تتردد السنة** بالضرورة كل سنة.

## 4. التبويبات (`.tab`)
- نصوص العناوين: "الرئيسية"، "نبذة"، "مهارات"، "مشاريع"، "تواصل".
- **يمكن** أن تكون hardcoded per language أو مُحمّلة dynamically.

## 5. العناوين الرئيسية (`h1`)
- الصفحة الرئيسية: "Abdullah Mohammed Hussein" (يمكن **الاحتفاظ internationals**.
- الصفحات الأخرى: "نبذة عني"، "مهارات"، "المشاريع"، "تواصل" **يمكن ترجمتها**.

## 6. العناصر الثابتة (لا تُترجم)
- الأسماء الخاصة: "عبدالله محمد حسين"، "A98".
- أسماء المنصات: "GitHub", "LinkedIn", "X", "Instagram", "WhatsApp" (تترك internationales).
- الأرقام: "2026", "201012012544".
- الرموز: "⎇", "✓", "↗".
- أيقونة A98.
