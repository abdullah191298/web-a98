# نظام الترجمة ثنائي اللغة (العربية / الإنجليزية)

يدعم الموقع نظام ترجمة ثنائي اللغة بين العربية (`ar`) والإنجليزية (`en`) مع حفظ تفضيل المستخدم في `localStorage`.

---

## 1. تخزين تفضيل المستخدم

يتم تخزين اختيار اللغة في `localStorage` تحت مفتاح `site-lang`.

- القيم الممكنة: `"en"` للإنجليزية، `"ar"` للعربية.
- عند أول دخول، القيمة الافتراضية هي `"en"` (إنجليزية).
- يتم حفظ الاختيار تلقائياً عند تغيير اللغة من قبل المستخدم.

```javascript
// في js الرئيسي (main.js)
const storedLang = localStorage.getItem('site-lang');
const defaultLang = 'en'; // الإنجليزية هي الافتراضية
const currentLang = storedLang || defaultLang;
```

---

## 2. تطبيق اللغة على الصفحة

عند تغيير اللغة، يتم تطبيق التغييرات التالية على عنصر `<html>`:

```javascript
document.documentElement.setAttribute('lang', currentLang);        // "en" أو "ar"
document.documentElement.setAttribute('dir', currentLang === 'ar' ? 'rtl' : 'ltr');
```

تتم هذه العملية في دالة `updateUI(k)` داخل `assets/js/main.js` عند كل تغيير للغة وعند تحميل الصفحة لأول مرة.

---

## 3. تحديث نصوص الواجهة

يتم تحديد العناصر القابلة للترجمة باستخدام سمة `data-key` في ملفات HTML. عند تغيير اللغة، تقوم دالة `updateUI` بتحديث `textContent` أو `innerHTML` لكل عنصر بناءً على القيمة المقابلة في كائن `translations` الموجود في `assets/js/translations.js`.

```javascript
function updateUI(k) {
  document.querySelectorAll("[data-key]").forEach(el => {
    const key = el.getAttribute("data-key");
    const val = translations[k] && translations[k][key];
    if (val) {
      if (el.tagName === "INPUT" || el.tagName === "TEXTAREA") el.placeholder = val;
      else if (/<[a-z][\s\S]*>/i.test(val)) el.innerHTML = val;
      else el.textContent = val;
    }
  });
}
```

### قواعد إضافة نصوص قابلة للترجمة جديدة

1. أضف سمة `data-key="المفتاح_الفريد"` إلى العنصر في ملف HTML.
2. أضف النص المقابل في `assets/js/translations.js` تحت كلا اللغتين `ar` و `en`.
3. إذا كان النص يحتوي على وسوم HTML (مثل `<strong>`)، استخدم `innerHTML` تلقائياً (يتم الكشف عنه في الكود).

---

## 4. أزرار تغيير اللغة

يوجد زرين في شريط العنوان (`.lang-switcher`) لكل صفحة:

| الزر | `data-lang` | النص عند التفعيل |
|------|-------------|-------------------|
| 영어 | `en` | `EN` |
| العربية | `ar` | `AR` |

عند النقر على أي زر، يتم استدعاء `updateUI` مع لغة الزر المحددة، ويُحدّث الزر النشط باستخدام كلاس `.active` وسمة `aria-pressed`.

---

## 5. تكامل مع المكونات

| المكون | السلوك عند تغيير اللغة |
|--------|------------------------|
| التبويبات (`.tab`) | يُحدّث النص حسب اللغة، ويُحتفظ بـ `aria-current="page"` على الصفحة الحالية |
| أزرار النسخ (`data-copy`) | تعمل بشكل مستقل عن اللغة، ولكن رسالة الحالة `.copy-status` تتغير حسب اللغة |
| نموذج التواصل (`.contact-form`) | التسميات، الأزرار، ورسائل الحالة تتغير حسب اللغة |
| شريط الحالة (`.statusbar`) | النصوص القابلة للترجمة تُحدّث (مثل "جاهز"، "UTF-8"، إلخ) |

---

## 6. الثوابت التي لا تُترجم

| العنصر | التفاصيل |
|--------|----------|
| الشارة | `A98` تظل كما هي في اللغتين |
| الأسماء الخاصة | "عبدالله محمد حسين" تظل كما هي |
| أرقام الهواتف | `+20 101 201 2544` تبقى بنفس التنسيق |
| التواريخ | `2026` تبقى كما هي |
| أسماء المنصات | `GitHub`, `LinkedIn`, `X`, `Instagram`, `WhatsApp` تظل دولية |
| الرموز | `⎇`, `✓`, `↗` تظل كما هي |
| اختصارات تقنية | `API`, `HTML`, `CSS`, `JavaScript`, `URL` تترك كما هي |
| عبارة "قريباً نبدأ التسجيل" | لا تُترجم (phrase exact في صفحة المشاريع) |

---

## 7. قواعد الاتجاه (RTL / LTR)

| العنصر | الاتجاه |
|--------|--------|
| الصفحة (`<html>`) | `rtl` للعربية، `ltr` للإنجليزية |
| النافذة (`.window`) | `ltr` دائماً (واجهة طرفية) |
| شريط العنوان (`.titlebar`) | `ltr` |
| شريط التبويبات (`.tabbar`) | يتبع اتجاه الصفحة (`rtl` للعربية) |
| نموذج التواصل (`.contact-form`) | يتبع اتجاه الصفحة |
| الحقول اللاتينية (الأرقام، المعرّفات) | تُعزل باتجاه `ltr` عبر كلاس `.ltr` |

---

## 8. اختبارات اللغة

عند إضافة نصوص جديدة أو تعديل اللغات، يجب التحقق من:

- [ ] ظهور النصوص بشكل صحيح في كلتا اللغتين على جميع الصفحات الخمس
- [ ] عدم وجود `overflow-x` بسبب طول النص العربي على المقاسات المختلفة (1440px, 500px, 390px)
- [ ] كفاية `margin` و `padding` للنصوص العربية الطويلة
- [ ] عدم قطع النصوص في الأزرار
- [ ] اتجاه `rtl`/`ltr` صحيح على `<html>` وعناصر النافذة
- [ ] ثبات اختيار اللغة عند التنقل بين الصفحات عبر `localStorage`
- [ ] ظهور رسالة الحالة `[ok]` / `[err]` بلغة خاطئة عند النسخ أو إرسال النموذج

---

## 9. حذف التفضيل

للعودة إلى الإعدادات الافتراضية (الإنجليزية):

```javascript
localStorage.removeItem('site-lang');
```

أو يمكن توفير زر "إعادة الضبط" في الإعدادات مستقبلاً.

## 11. أمثلة على الاستخدام

### إضافة نص جديد قابل للترجمة

**في ملف HTML:**
```html
<p data-key="my_new_text">نص افتراضي بالعربية</p>
```

**في `assets/js/translations.js`:**
```javascript
ar: {
  my_new_text: "نص افتراضي بالعربية",
  // ...
},
en: {
  my_new_text: "Default English text",
  // ...
}
```

### تغيير اللغة برمجياً

```javascript
updateUI("ar"); // تحويل كل شيء إلى العربية
updateUI("en"); // تحويل كل شيء إلى الإنجليزية
```
